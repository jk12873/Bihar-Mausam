# Bihar Mausam (बिहार मौसम)

Production-Ready Android Weather Application delivering real-time weather information, 24-hour hourly forecasts, 7-day outlooks, and statewide meteorological insights for all 38 districts of Bihar, India.

---

## 🌟 Key Features

1. **Complete 38 Districts of Bihar Support**:
   - Centralized dataset with authentic administrative headquarters coordinates.
   - Bilingual presentation in English and Hindi (e.g. *Patna (पटना)*, *Gaya (गया)*, *Muzaffarpur (मुज़फ़्फ़रपुर)*).
   - Division groupings (Patna, Tirhut, Saran, Darbhanga, Kosi, Purnia, Bhagalpur, Munger, Magadh) and regional zones (North vs. South Bihar).

2. **Free Weather API Integration (Open-Meteo)**:
   - Primary data provider: **Open-Meteo** (Forecast API & WMO meteorological mapping).
   - Metric parameters with `Asia/Kolkata` (IST) timezone.
   - Zero API key required, zero paid subscriptions or paywalls.
   - Fields captured: Current temp, feels-like, today's high/low, relative humidity, wind speed & compass direction, UV index, precipitation likelihood, rainfall amounts, cloud cover, sunrise & sunset times.

3. **Interactive 24-Hour Custom Canvas Chart**:
   - Hardware-accelerated cubic Bézier curve chart built natively in Jetpack Compose.
   - Gradient fill under curve, interactive point scrub, and hourly rain probability bars.

4. **Offline Resilience with Room Database**:
   - Cache-first strategy: automatically caches weather payloads in local SQLite via Android Room.
   - Fallback offline reading when traveling through low-connectivity rural zones.
   - Clear visual status badge distinguishing live vs cached data with timestamp.

5. **Statewide Weather Analytics**:
   - Average temperature calculated across Bihar districts.
   - Hottest, coolest, rainiest, and windiest district indicators.
   - Regional breakdown comparing North Bihar vs South Bihar climate.
   - Clear attribution disclaimers distinguishing numerical averages from official government bulletins.

6. **Search & Location Options**:
   - Instant search supporting English and Devanagari Hindi queries.
   - Category filtering (Rainy, Clear, Cloudy, Hot >35°C) and sorting (Name, Temp, Rain).
   - Optional GPS location lookup via Android `LocationManager` to automatically select the nearest Bihar district (falls back gracefully to manual selection).

7. **User Preferences**:
   - Celsius (°C) and Fahrenheit (°F) toggle.
   - Wind speed in km/h or m/s.
   - Default district selection and manual cache management.

## 🏗️ Architecture & Technology Stack

- **Platform**: Native Android (Min SDK 24, Target SDK 36)
- **Language**: Kotlin
- **UI Toolkit**: Jetpack Compose with Material Design 3 (M3)
- **Architecture**: MVVM (Model-View-ViewModel) + Repository Pattern
- **Networking**: Retrofit 2.12 + OkHttp 4.10
- **Serialization**: Moshi 1.15 with Kotlin reflection & KSP codegen
- **Local Persistence**: Android Room 2.7
- **Asynchronous Flow**: Kotlin Coroutines & `StateFlow` / `collectAsStateWithLifecycle`
- **Testing**: JUnit 4 & Robolectric

## 🚀 Building & Running the Project

### Prerequisites
- Android Studio Ladybug / Meerkat or newer
- JDK 17 or JDK 21 configured in Gradle Settings
- Android SDK Platform 36

### Build Steps
1. Clone or open the project folder in Android Studio.
2. Let Gradle sync dependencies automatically.
3. Run the unit tests via terminal or IDE:
   ```bash
   gradle :app:testDebugUnitTest
   ```
4. Run or debug on an Android device or emulator running Android 8.0 (API 26) or higher.
